Privacy policy

Effective 20 October 2026

This policy describes the personal desktop version of Workora and its optional Google Drive backup and recovery connection. The owner operates this private installation. This information website does not provide a hosted Workora account or access to the owner's workspace.

Information kept on the owner's computer

Workora stores conversations, attachments, project settings, command output, and other workspace records in local application storage. Local AI runtimes process requests on that computer. If the owner configures a separate online AI, search, or other integration, requests sent through that feature are also handled by the selected provider.

Google information accessed

When an account is connected, Workora receives OAuth access and refresh tokens. It reads the account's Drive permission identifier to distinguish connected accounts, storage quota information, and file metadata and contents required for backup verification and recovery.

The current desktop client requests these Google Drive permissions:

  • Read-only Drive access: permission to view and download Drive files. This is a broad Google permission; the implemented backup and recovery features constrain their file operations to Workora-owned folders and marked files.
  • Per-file Drive access: permission to create and manage files opened or created with Workora.

How Drive is used

Workora uploads public-source knowledge records with source links and retrieval dates, backup manifests, and experimental model-training datasets, adapter checkpoints, optimizer state, and evaluation records. These are used to preserve, verify, and restore Workora's learning work. Current training examples are public or generated exercises; private conversations and project attachments are excluded from this Drive backup flow.

Workora verifies archived file sizes and checksums before treating a backup as complete. It may download those archives to test or perform recovery. The desktop connection does not mirror the entire Drive account or index unrelated Drive documents.

Storage, retention, and deletion

Google OAuth credentials and resumable upload-session information are protected on the Windows computer with current-user Windows Data Protection API encryption. They are not placed in published web pages or shared-conversation snapshots. Workora retains its local workspace, accumulated source memory, and saved model updates unless the owner removes them. Some verified temporary backup copies can be removed after successful remote verification.

Drive backups remain in the connected account until the account owner deletes them in Google Drive. Deleting a conversation locally does not delete unrelated Drive backups. Revoking Google access stops future authorized transfers but does not automatically remove existing local files or cloud copies. To remove data, delete the relevant Workora local files and Drive files separately.

Sharing and use of Google data

Workora does not sell Google user data, use it for advertising, or use private Google Drive contents to train a generalized AI model. Google user data is used only to provide the requested connection, backup, verification, and recovery features. Workora's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

An explicit conversation Share action creates a separate read-only snapshot of the selected conversation text, activity history, and attachment names. Attachment contents and Google credentials are excluded. Anyone with that link can read the snapshot while it is available; the owner can revoke it. Drive backup itself does not publish conversations or make Drive files public.

This information website

The Workora information pages contain no account sign-in, advertising, analytics scripts, or file-upload forms. GitHub Pages hosts this website. GitHub processes ordinary request information such as IP addresses and browser headers to deliver and protect it under the GitHub General Privacy Statement.

Your choices and support

Choose whether to connect each Google account and whether to enable public-source study. You can revoke Workora's connection from your Google Account connections. Existing Drive copies remain under your account's control. For access, deletion, or privacy questions about the private installation, contact its owner through the support email shown on Workora's Google consent screen.

Updates

The effective date will change when this policy is updated. Changes to data use or requested Google permissions should be reviewed before using the affected feature.
